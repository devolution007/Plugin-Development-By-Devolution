# Product Listing

## Product name

Cloud Gallery Connector for Microsoft 365

## Short description

Connect WordPress to Microsoft 365 and showcase authorized OneDrive or SharePoint folders as responsive galleries, organized file lists, or interactive folder browsers—using simple shortcodes.

## Full description

Cloud Gallery Connector for Microsoft 365 makes it easy to display selected OneDrive and SharePoint content on a WordPress website without uploading duplicate files to the Media Library.

After a site administrator connects an authorized Microsoft 365 account, the plugin provides a built-in folder browser for locating OneDrive folders and SharePoint document libraries. It then generates a ready-to-use shortcode that can be placed on any WordPress page or post.

Choose from a polished image gallery, a practical file-list layout, or an interactive folder browser that allows visitors to navigate organized cloud content. Responsive styling presents content cleanly across desktop, tablet, and mobile screens, while the included accessible lightbox gives visitors a focused way to view images.

### Key features

- Connects WordPress to OneDrive and SharePoint through Microsoft Graph.
- Displays files as responsive galleries, lists, or interactive folder browsers.
- Generates simple, folder-specific WordPress shortcodes.
- Includes an accessible image lightbox.
- Supports configurable gallery columns, item limits, and image-only filtering.
- Keeps source files in Microsoft 365 instead of duplicating them in WordPress.
- Uses cached Microsoft Graph responses to improve performance.
- Restricts connection settings to WordPress administrators.
- Includes no analytics, advertising, or telemetry.

### Requirements

- WordPress 6.0 or newer
- PHP 7.4 or newer
- A Microsoft 365 account
- A Microsoft Entra app registration with the required delegated Microsoft Graph permissions

### Important note

The plugin does not change Microsoft sharing permissions. Only embed folders containing content intended for the audience of the WordPress page. This is an independent connector and is not affiliated with, endorsed by, or sponsored by Microsoft.
